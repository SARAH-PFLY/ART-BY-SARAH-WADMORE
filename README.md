# Art by Sarah Wadmore

[Visit the website](https://sarah-pfly.github.io/ART-BY-SARAH-WADMORE/)

A responsive, artwork-first gallery with a full-width wall of images: four columns on desktop, two on mobile, and varied tile heights. Select any artwork to view the complete piece in a fullscreen viewer with keyboard, arrow and swipe navigation.

## Artworks

The gallery currently includes labelled demo tiles until original artworks are added. Upload artwork images and update `artworks.json` to replace them. See [GALLERY.md](GALLERY.md) for image setup and controls.

## Publishing

The link above is the repository's standard GitHub Pages address. To publish, select **Settings → Pages → Deploy from a branch → main → / (root) → Save**. GitHub Pages must finish deployment before the website is available.

This is a static website; no dependencies or build step are required.
